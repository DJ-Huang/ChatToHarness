    应用级 MCP 服务
    在 ChatToHarness 中连接工具服务，所有客户端共用；无需创建 Agent。
    
          
    已启用且受信任的 MCP 服务将放行全部工具，包括以后新增的工具；关闭后恢复逐项权限。切换时，权限受影响的待确认请求或调用会被取消。
    此设置仅管理本机工具权限，ChatGPT 仍可能要求授权。
    
          
    先信任服务，再逐项授权工具。新增或变更的工具默认禁用，客户端可能需要刷新工具目录。
    
        
    
        
    确认信任此服务
    本地服务以当前用户身份运行；工作目录白名单不会限制第三方进程。仅连接你信任的服务。
    
        
    
          
    添加 MCP 服务
    保存配置不会授权工具。请勿将密钥写入命令参数或服务地址。
    
          
    
            
    以小写字母开头，可含数字、下划线或连字符，保存后保持不变。
    
            
    
            
    
            
    包含本机确认的等待时间，最长 90 秒。
    
          
    
          
    
            
    
            
    
            
    
            
    
            
    Mac / Windows 启动覆盖
    使用 darwin 和 win32；未填写的字段沿用上方配置。
    
          
    
          
    
            
    远程服务使用 HTTPS；本机回环地址可使用 HTTP。
    
            
    
          
    
          
    环境变量与请求头的新值由系统加密保存；已保存的值仅显示 secretRef 引用。保留引用可继续使用，缺失的密钥需要重新填写。
    
          
    
        
    
        
    导入与导出
    支持本应用配置和 mcpServers JSON。导入的服务保持停用，密钥、信任与工具授权不会随导出转移。
