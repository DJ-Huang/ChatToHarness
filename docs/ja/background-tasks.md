# バックグラウンドタスクを開始・確認・取消する

[English](../en/background-tasks.md) | [简体中文](../zh-CN/background-tasks.md) | [日本語](../ja/background-tasks.md)

> ChatToHarness 0.6.0 対象。

## 目的

時間のかかる作業を動かし、切断後も同じタスクを確認します。

## 始める前に

プロジェクト、コマンド、出力先を決め、重要なファイルを保存します。通常はクライアントから依頼します。

## 操作手順

1. 永続バックグラウンドタスクとして実行するよう明示し、返されたタスク ID を残します。
2. 同じタスクの状態とログを取得します。登録成功と完了は別です。
3. 終了したらログ末尾だけで判断せず、結果・終了状態・成果物を確認します。
4. 切断、アプリ再起動、クライアントのタイムアウト後は、元の ID で先に確認します。
5. 取消時はタスクを特定し、停止または完了を確認するまで状態を取得します。

### コピーして使える例文

例のパスは許可済みのプロジェクトの絶対パスに置き換えます。Windows では自分のドライブのパスを使ってください。

```text
/Users/demo/ExampleProject で指定したコマンドを永続バックグラウンドタスクとして実行し、ID を残してください。重複起動せず同じ ID を確認し、完了時は終了状態と成果物のパスを教えてください。
```

操作の順序を示す図です。クライアントが実際に実行した結果ではありません。

## 完了時の状態

進捗、上限付きの出力、最終状態を確認できます。プロジェクトのタスク一覧から探すこともできます。

## うまくいかない場合

ウィンドウを閉じる、接続を止める、アプリを終了するだけでは永続タスクが止まる保証はありません。不明な状態では成果物も確認します。自動で再実行されません。重要な結果はファイルにも保存してください。
