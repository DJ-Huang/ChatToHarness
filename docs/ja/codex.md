# Codex に接続する

[English](../en/codex.md) | [简体中文](../zh-CN/codex.md) | [日本語](../ja/codex.md)

> ChatToHarness 0.6.0 対象。

## 目的

現在の Codex 製品に用意された入口から、同じ本機の環境を利用します。

## 始める前に

本機のアプリを起動したままにし、トンネルを準備完了にします。アカウントの組織との関連付けが必要です。

## 操作手順

1. 現在の Codex 製品が対応する Tunnel またはプラグインの接続手順を開きます。入口は製品・アカウント・バージョンで異なります。
2. 本機のアプリが管理する同じトンネルを選び、組織の権限を確認します。
3. ツールの検出後、プロジェクトの絶対パスを伝え、まず概要の取得を依頼します。
4. 実際の結果を確認してから、初回タスクの手順で専用ファイルを試します。

![Codex に接続する](../images/help/ja/help.png)

1 クライアント接続案内、2 アプリ更新。 現在のリポジトリの画面と隔離サンプルによる操作例です。実際の接続やツール実行の成功を示していません。

## 完了時の状態

Codex から本機のツールを呼び出せます。既存のトンネルを再利用し、別の実行プログラムを起動する必要はありません。

## うまくいかない場合

入口がない場合は公式案内や管理者に確認します。トンネルのアドレスを通常のサービス URL として入力したり、未確認のローカル設定を転用したりしないでください。公式対応と端末での成功は別です。

[OpenAI 公式接続ガイド](https://developers.openai.com/api/docs/guides/secure-mcp-tunnels)
