# コンソールの見方

[English](../en/console-tour.md) | [简体中文](../zh-CN/console-tour.md) | [日本語](../ja/console-tour.md)

> ChatToHarness 0.6.0 対象。

## 目的

設定を始める場所と、結果を確認する場所を把握します。

## 始める前に

ChatToHarness を開きます。キーの入力前でも画面を確認できます。

## 操作手順

1. 概要：接続状態、本機のツール、初回利用の手順を確認し、接続や停止を行います。
2. 接続設定：トンネルと実行用キーを保存し、起動時の自動接続を設定します。
3. 作業フォルダー：ファイルツールの対象フォルダーと工程規約の自動読み込みを設定します。
4. MCP Servers：外部サービス、信頼、ツールの権限を管理します。
5. リアルタイムログ：接続とツールの状況を確認します。この項目を展開すると実行履歴が開けます。
6. 接続とヘルプ：クライアントの案内、ヘルプ、更新を確認します。言語はサイドバー下部で変更します。

![コンソールの見方](../images/help/ja/overview.png)

1 接続状態、2 機能の入口、3 初回利用の手順。 現在のリポジトリの画面と隔離サンプルによる操作例です。実際の接続やツール実行の成功を示していません。

## 完了時の状態

設定と問題調査の入口を見分けられます。実行履歴は最初は折りたたまれています。

## うまくいかない場合

実行履歴が見えない場合はログの項目をもう一度押すか、ログ画面のショートカットを使います。別バージョンでは表示が異なる場合があります。
