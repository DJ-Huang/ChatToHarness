# 接続の認証情報を変更・消去する

[English](../en/credentials.md) | [简体中文](../zh-CN/credentials.md) | [日本語](../ja/credentials.md)

> ChatToHarness 0.6.0 対象。

## 目的

実行用キーを更新するか、保存した接続認証情報の利用をやめます。

## 始める前に

本機のアプリで操作し、キーをチャットやログに貼り付けないでください。実行中の処理を先に確認します。

## 操作手順

1. 接続設定で Tunnel ID を確認します。
2. 変更は Runtime API Key に新しい値を入力し、保存して接続します。
3. 保存後は入力欄が空になり、保存済みと表示されます。以前のキーを再表示できないのは通常の動作です。
4. 消去する場合は認証情報をクリアする操作を選び、接続が停止したことを確認します。
5. 再開時は有効なキーを入力して接続します。

![接続の認証情報を変更・消去する](../images/help/ja/connection.png)

1 トンネル ID、2 本機の実行用キー、3 保存して接続。 現在のリポジトリの画面と隔離サンプルによる操作例です。実際の接続やツール実行の成功を示していません。

## 完了時の状態

変更後は新しい認証情報を使います。消去しても作業フォルダーや規約設定は残ります。

## うまくいかない場合

OS の認証情報アクセス画面が出たら対応します。復号できない場合は再入力し、データフォルダー全体を削除しないでください。実行用キーとクライアント／API のキーは用途が異なります。
