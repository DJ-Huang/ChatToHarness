# よくある質問と問い合わせ

[English](../en/faq.md) | [简体中文](../zh-CN/faq.md) | [日本語](../ja/faq.md)

> ChatToHarness 0.6.0 対象。

## 目的

よくある動作を確認し、調査しやすい問題報告を用意します。

## 始める前に

バージョン、OS、発生時刻を控えます。

## 操作手順

1. スマートフォンで使えるか：対応チャットから依頼できますが、本機とアプリは動かしたままにします。
2. 閉じれば止まるか：止まりません。停止と終了は別で、永続タスクは明示的な取消が必要です。
3. 確認が複数ある理由：アプリ、クライアント、OS、外部サービスはそれぞれ権限を管理します。
4. 開発環境は必要か：実行用の構成は同梱されますが、外部ツールには追加要件があります。
5. 問い合わせは公式リポジトリの Issues に、環境、手順、期待と実際の結果、確認済みの記録を添えます。
6. 既存の問題を探し、キーや私有プロジェクト全体ではなく最小例を共有します。

![よくある質問と問い合わせ](../images/help/ja/workflow.svg)

操作の順序を示す図です。クライアントが実際に実行した結果ではありません。

追加のツール診断には、最近の呼び出し、利用状況、現在の設定を読み取りで要約させます。設定変更は影響を確認してから行い、フォルダー許可は本機のアプリで変更します。内蔵 Desktop Commander のフィードバックは別のフォームを開き、本製品の Issues とは異なります。

## 完了時の状態

再現方法と失敗した段階が分かる報告になります。

## うまくいかない場合

未確認のクライアントや環境は未確認と明示します。権限は提供サービスや管理者が設定するもので、問題報告だけでは付与されません。

[GitHub Issues](https://github.com/DJ-Huang/ChatToHarness/issues)
