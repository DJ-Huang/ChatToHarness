# ファイルを探して整理する

[English](../en/files.md) | [简体中文](../zh-CN/files.md) | [日本語](../ja/files.md)

> ChatToHarness 0.6.0 対象。

## 目的

必要なファイルを見つけ、指定した範囲だけを整理します。

## 始める前に

対象を作業フォルダーに追加して保存します。Mac は /Users/demo/ExampleProject、Windows は C:\Users\demo\ExampleProject などの絶対パスを使います。

## 操作手順

1. まず一覧を取得し、名前・種類・サイズで対象を絞ります。必要ならファイル情報も確認します。
2. フォルダーの作成では場所と名前を指定します。
3. 移動や名前変更では、元と先の場所、対象の一覧を伝えます。
4. 同名の移動先があれば上書きせず報告するよう依頼します。
5. 操作後に元と先の一覧を読み直し、実際の結果を確認します。

### コピーして使える例文

例のパスは許可済みのプロジェクトの絶対パスに置き換えます。Windows では自分のドライブのパスを使ってください。

```text
/Users/demo/ExampleProject の直下にあるファイルの名前・種類・サイズを一覧にしてください。移動・名前変更・削除はしないでください。
```

![ファイルを探して整理する](../images/help/ja/files.svg)

操作の順序を示す図です。クライアントが実際に実行した結果ではありません。

## 完了時の状態

指定した名前や配置になり、無関係なファイルは変わっていません。

## うまくいかない場合

アクセスできないときはフォルダーの許可を確認します。リンクの実際の参照先も許可範囲内である必要があります。整理全体を一括で元に戻す機能や汎用のごみ箱はありません。
