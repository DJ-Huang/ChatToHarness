# 初めて接続する

[English](../en/first-connection.md) | [简体中文](../zh-CN/first-connection.md) | [日本語](../ja/first-connection.md)

> ChatToHarness 0.6.0 対象。

## 目的

クライアントの依頼を受け取れるように、本機のアプリを準備します。

## 始める前に

アプリをインストールし、Tunnel ID、Runtime API Key、試用フォルダーを用意します。

## 操作手順

1. 接続設定で Tunnel ID を入力します。クライアントでも同じトンネルを選びます。
2. Runtime API Key を入力します。保存後は保存済みの表示だけになります。
3. 作業フォルダーで試用フォルダーを追加し、設定を保存します。
4. 接続設定に戻り、保存して接続を選びます。
5. 保存済み認証情報へのアクセスを OS に求められたら、システム画面で許可します。
6. 概要に戻り、本機の確認が終わってトンネルが準備完了になるのを待ちます。

![初めて接続する](../images/help/ja/connection.png)

1 トンネル ID、2 本機の実行用キー、3 保存して接続。 現在のリポジトリの画面と隔離サンプルによる操作例です。実際の接続やツール実行の成功を示していません。

## 完了時の状態

準備完了は本機が依頼を受け取れる状態です。ChatGPT または Codex でも同じトンネルを選び、実際にツールを呼び出して確認します。

## うまくいかない場合

失敗時は組織、Tunnel ID、キーの権限を確認し、ログを調べます。同じトンネルを別のツールから重複起動しないでください。
