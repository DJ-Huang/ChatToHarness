# 言語・自動接続・バックグラウンド動作

[English](../en/preferences.md) | [简体中文](../zh-CN/preferences.md) | [日本語](../ja/preferences.md)

> ChatToHarness 0.6.0 対象。

## 目的

言語を選び、起動時とウィンドウ・トレイの動作を理解します。

## 始める前に

アプリを開きます。画面の言語とクライアントの言語は別に設定できます。

## 操作手順

1. サイドバー下部で中国語・英語・日本語を選びます。すぐに反映され、選択は保存されます。
2. 接続設定で起動時の自動接続を設定し、保存します。OS ログイン時の自動起動とは異なります。
3. ウィンドウを閉じてもバックグラウンドで動きます。メニューバーやトレイのアイコンで戻れます。
4. 右クリックから接続、停止、ログ、更新、終了を選べます。
5. 完全に終了するには ChatToHarness を終了する操作を使います。起動済みなら通常は既存ウィンドウが戻ります。

自動接続の右側にある「プロキシ構成」から、直接接続、システム、手動を選択できます。手動では HTTP、HTTPS、SOCKS5 とサーバー、ポートを指定します。除外アドレスはドメイン、IP、CIDR に対応し、ローカルアドレス、一般的なプライベート範囲、現在のネットワークの実際のサブネットが既定で入力されます。ネットワーク変更後は既定値に戻して更新できます。トンネル認証情報がなくても設定を保存できます。保存後に再接続してください。安全なトンネルに適用され、OS のプロキシ設定は変更しません。

接続モードはラジオボタンで選択します。手動設定にはユーザー名とパスワードの認証（HTTP/HTTPS は Basic、SOCKS5 はユーザー名・パスワード）を指定できます。プロキシパスワードは OS のセキュアストレージで自動的に暗号化して保存されます。パスワード欄を未編集のまま空欄にすると既存の認証情報を維持します。削除するには、パスワード欄を編集して空にして保存します。空欄では既存のパスワードを維持しますが、サーバーやユーザー名を変更した場合は再入力が必要です。システムに保存されたパスワードは自動継承しません。ローカル・LAN の除外チェックで対応する範囲を追加できます。接続テストは未保存の設定を使用し、Runtime API Key は不要です。接続先の HTTP 401/403 は到達可能なことを示すだけで、業務上の認可成功ではありません。保存後に再接続してください。キャンセルはプロキシの変更と入力したパスワードを破棄します。

## 完了時の状態

言語変更に再接続は不要です。ウィンドウを閉じても依頼は受け付けるため、停止や終了は別途行います。

## うまくいかない場合

初回はシステム言語に従い、未対応なら英語になります。その後は保存した選択を使います。終了しても永続タスクは別途取消が必要です。スリープやシャットダウン中は遠隔利用に影響します。
