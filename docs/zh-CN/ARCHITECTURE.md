# ChatToHarness 架构

[English](../en/ARCHITECTURE.md) | [简体中文](../zh-CN/ARCHITECTURE.md) | [日本語](../ja/ARCHITECTURE.md)

执行链路为支持的客户端 → OpenAI Secure MCP Tunnel → 本机 Tunnel runtime → 经过认证的本机私有 IPC → 应用级 MCP 网关。内置工具由网关交给工程规范代理与 Desktop Commander；已授权第三方工具通过各自的 MCP 连接转发。客户端继续只使用现有 Tunnel；私有 IPC 与健康端点不是公开 MCP 接口。

## 桌面层

Electron 主进程管理配置、系统加密存储、单实例、窗口、后台图标和连接队列。HTML/CSS/JavaScript 提供独立设置与帮助页面；受限 preload 暴露设置、目录选择、状态订阅及连接操作。渲染器禁用 Node，启用沙箱、上下文隔离、导航限制和外部链接白名单。

窗口关闭只隐藏。停止与退出增加 actionEpoch，取消排队的自动连接及保存后的连接续步。窗口完成加载后才开始自动读取密钥，避免系统授权挡住初次呈现。状态只包含密钥是否保存，不返回明文或密文。

Mac 保留 LocalHarness 的内部名称、应用标识和状态目录，显示名称为 ChatToHarness；Windows 使用独立系统数据目录。系统加密不可用时拒绝明文回退，读取失败保留原设置。Windows 的用户级系统加密不表示同用户其他程序无法访问。

## 平台与受管进程

平台适配层提供组件位置、默认 Shell、用户环境、通道命令及进程监督。Mac 使用进程组和拥有进程清理；Windows 用编译的 Job Object 辅助进程约束受管子树，进程退出关闭 Job。Tunnel 密钥只通过环境传入，工具代理启动 Desktop Commander 前移除该变量。

平台组件由固定版本和校验值准备，自带 Node；工具配置与日志位于私有数据目录，保留用户真实 HOME／USERPROFILE，遥测关闭。Desktop Commander 配置目录适配只接受已知源码匹配，失配停止构建。

## 应用级 MCP 网关

MCP 服务配置属于 ChatToHarness，由 Tunnel 客户端共享，与具体 Agent 无关。Electron 主进程持有配置、密钥、信任、工具策略和每个服务的独立连接。Tunnel 的 stdio 入口通过经过认证的本机私有通道访问网关，不能管理配置或批准调用。Unity、浏览器均作为普通第三方 MCP 服务；本次不增加 Agent 运行器或 Computer Use 驱动。

连接支持本地 `stdio` 与本地／远程 Streamable HTTP。远程必须使用 HTTPS，HTTP 仅接受回环地址；不支持 OAuth 或旧式 HTTP+SSE。SDK 固定为 `1.32.1`，上下游独立协商并显示实际协议版本，仅接受 `2026-07-28` 的服务不兼容。配置可覆盖 Mac／Windows 的启动参数。密钥值单独使用系统加密保存，配置与导出只保留引用，界面状态只显示是否已保存。导入先预览、默认禁用，不启动命令；导出不携带信任记录或工具授权。

内置工具保留原名称，第三方使用稳定的 `serverId__toolName` 命名空间并按注册表路由。发现读取完整分页，列表变更刷新注册表；默认逐项授权模式下，新增或定义变化的工具重新授权。每个工具为禁用、直接调用或每次本机确认，服务声明的只读注解不产生授权。首次连接确认实际命令或目标 URL 的信任，启动目标变化后重新确认；调用确认绑定工具、不可变参数和连接版本，并受调用总截止限制。

“允许所有工具”默认关闭并保存在本机设置中，不随配置导出。开启后，已启用且受信任的第三方服务全部工具直接调用，包括之后新增或变更的工具；不自动启用或信任服务。关闭后恢复原逐项策略，期间真实定义变化仍会撤销旧的逐项授权。切换仅取消有效权限发生变化的待确认或在途调用，不重放调用或重建连接；已有工具定义及注解保持不变，仅在可见工具集合变化时发送目录通知。该开关只管理 ChatToHarness 本机权限，ChatGPT 等客户端仍独立决定是否确认调用。

工具列表仅重排不影响授权、待确认调用或正在执行的调用。工具删除或定义变化只取消对应工具的调用，不打断定义未变的其他工具；未变工具保留原对象身份，后续单项权限修改仍能取消其调用。

第三方参数与输入／输出 Schema 原样保留，不注入工程上下文或执行内置参数清理；结果保留结构化内容、图片与工具错误。网关为具备相应协议能力的客户端提供原生资源列表／模板／读取及提示词列表／获取，并为仅支持工具的客户端提供四个只读回退工具；不增加资源订阅、completion、sampling、elicitation 或完整 MCP Apps GUI 宿主能力，第三方工具结果中任意资源 URI 也不保证自动改写，工具结果可带资源链接。工具变化后，客户端可能仍需自行刷新工具目录。

每个服务独立管理连接和进程树，重复检查复用已有连接，Tunnel 重连不重启健康服务。传输故障分别退避重连，认证、配置与协议错误需要修正。断线不重放调用，已转发但未返回的调用报告执行状态未知。转发给第三方的工具调用默认总截止 60 秒、最高 90 秒（含确认），消息大小上限 8 MiB；应用自有 Harness 任务与内容读取另有独立的超时及资源预算。日志记录服务、工具、耗时、授权结果与执行状态，以及连接阶段／代次、目录摘要与变更数量、网关会话和重复初始化次数；普通应用事件日志会脱敏且默认不复制完整参数／结果；但任务命令、限定输出、执行详情及编辑备份分别保存，可能包含用户内容，并非整个本机数据目录均经过加密。重复初始化与物理连接重建分别记录，不能仅凭初始化次数推断客户端授权失效。

停止连接会停止 Tunnel 和所有受管服务；单独禁用服务只处理该服务。关闭窗口继续后台运行。第三方 stdio 进程只接收基础运行环境与显式配置，不继承 Tunnel 密钥。工作目录白名单不是第三方进程沙箱，进程仍拥有当前用户的系统权限。

## Harness 服务、持久任务、授权与诊断（v0.6.0）

网关具有**三条独立的分发路径**：应用自身的 `app/harness-services.cjs` 直接提供工程概览、Git、产物、编辑和任务；`app/mcp-proxy.cjs` 的工程规范代理转发给官方 Desktop Commander；以及已启用、受信任的第三方 MCP 服务与 `app/mcp-content.cjs` 内容桥接。官方 Desktop Commander 的 25 个工具名保持兼容，但实际可见工具数量取决于已授权目录及已启用的服务。`get_harness_status` 返回构建、设备、连接和目录；“可用”不能替代实际调用验收。构建身份中的 commit、dirty 和源码 SHA 并非数字签名或完整供应链证明。

`get_project_overview`、`git_status`／`git_diff`／`git_log`、`get_file_result` 均受本机授权目录、分页与大小限制。规范匹配增加路径／globs、任务关键词、始终生效规则和可发现的 Skills；只有显式选择的 `skill_paths` 会加载 Skill 正文。上下文令牌只证明已经交付，不授予访问权，也不证明模型遵守。

`start_task` 持久保存项目与幂等键生成的身份、请求指纹和 worker claim，独立 worker 执行通过 Desktop Commander 策略验证的命令。仅收到任务登记信息时不代表命令已经结束；短等待内完成的任务会直接返回终态和有限输出。状态、结果、日志、列表和取消接口支持重连后查询；心跳丢失可能表示命令已经执行过，因此不会自动重放。**桌面 App 的停止连接或退出，并不保证结束独立的持久任务**，必须使用 `cancel_task` 并确认状态。默认时限 24 小时、最高 7 天，最多 4 个活跃任务、1,024 条任务身份；清理输出不会删除身份与防重放保护。

`apply_project_edit`／`undo_project_edit` 基于 UTF-8 内容哈希、幂等键和撤销备份，拒绝覆盖哈希已变化的文件；但哈希检查和随后文件操作并非能防止所有外部并发写入的原子事务。项目／工具级授权与可识别路径、服务配置及工具定义版本绑定，并不构成终端或第三方服务的系统级沙箱。全工具放行只针对已启用且受信任的外部服务，撤销许可不等于撤销已经发生的副作用。

`app/execution-history.cjs` 分别记录请求、执行结果、关联任务与**本机通道写入**；没有远端回执时，不能声称 ChatGPT 已收到。应用 JSONL 日志、执行记录及独立 worker 输出共享 50 MiB 可清理预算（约 40 MiB 开始清理），最多 10,000 条／7 天，单任务输出 4 MiB，详细诊断手动开启、份额 10 MiB、30 分钟后关闭。任务状态／防重放、编辑备份及其他数据不计入此预算。实时日志仅轮询有界页面，界面最多 400 条；高频事件可能跨轮询遗漏，不是无损审计流。脱敏属于尽力而为，也不代表所有任务输入与输出均已加密。详见[执行记录预算与清理](../execution-records.md)。

## 规范代理与搜索

`get_project_context(project_path, target_paths?, rule_paths?, skill_paths?, task?)` 保留项目、规范正文、索引和凭证，增加带 `blocks_writes` 的 `diagnostics`。项目范围决定规范作用范围，应用授权目录决定文件读取边界，两者分别检查；共享规则可跨项目读取，不能扩大目标或写入权限。AGENTS 缺失正常，引用失败软诊断，真正无法交付的适用 AGENTS 只阻断写入。

文件和搜索读取直接附带规范；有效凭证复用已交付正文。写入首次需要规范时返回正文与重试凭证，明确未执行。文件及目录元数据控制有界缓存，正文只有变化时重新读取和计算哈希，并合并并发加载；AGENTS 使用固定文件名检查，规则索引流式枚举并有明确上限。索引版本与已交付规范版本分开，无关索引变化不使写入失效。

`search_project` 直接使用已打包的 ripgrep，参数数组传递，不使用 Shell。默认字面量、2 秒、每页 100 条与前后 2 行；总匹配 1,000、保存 2 MiB、单页结果 64 KiB，最多并发 4 个，时间上限 10 秒。快照绑定项目与查询，闲置 5 分钟失效；完成、无匹配、超时、数量／体积上限和部分失败分别报告。原生流式搜索继续提供。

内置代理待处理请求有容量限制，内部显式等待最多 180 秒；外层网关使用更短的调用总截止时间。取消传给上下文及搜索，断开会清理等待表、缓存与搜索进程。未转发的失败标为 `not_started`，已转发超时为 `unknown`，不自动重放操作；迟到结果丢弃。继续读取和清理操作绑定来源句柄，不依赖全局当前项目；已知清理不要求重读规范。工具 schema、输出 schema 与真实行为注解同步维护，移除不可用的网页组件提示。

## 应用更新

独立 `Updater` 从固定 GitHub 仓库读取已公开稳定 Release，验证版本、平台、安装包地址、大小与 SHA-256（支持 `SHA256SUMS.txt`）。只通过主进程的 Electron `net.fetch` 联网，以支持系统代理；渲染器仍禁用网络与 Node。更新 IPC 复用主窗口来源校验，外部地址由主进程已验证的 Release 决定。

默认启动后 10 秒和此后每 24 小时检查；开关保存在独立偏好文件，手动与自动检查合并并发，不访问密钥或连接队列。下载必须由用户启动，流式校验后再次验证安装包，先断开受管进程再打开安装包并退出。失败保留可重试状态，退出取消下载；旧的私有更新缓存 7 天后在后续检查时清理。测试模式不启动自动联网。

## 构建与交付

GitHub Actions 在原生 Windows x64、Mac arm64 构建，校验打包资源、运行隔离窗口和安装检查。只有双平台通过且上传文件核验成功后，才自动正式发布带更新说明与 SHA-256 的稳定版，并直接调用官网部署；公开 Release 不覆盖。Pages 独立构建，首页下载只使用已公开稳定 Release，源码和页面均不保存用户配置或凭据。

运行和验收边界见 [VERIFICATION.md](VERIFICATION.md)，维护流程见 [docs/RELEASING.md](RELEASING.md)。

## 语言支持

软件通过 `app/locales.js` 和 `app/i18n.js` 共享窗口与原生菜单的翻译，覆盖静态文字、无障碍标签、运行状态和已知错误。首次采用系统语言，用户选择单独存入 `preferences.json`，与加密配置分开。语言接口直接更新菜单和状态，不进入连接队列，也不修改 `actionEpoch`。路径、凭据和工具输出不做翻译。

官网在根路径（英文）、`/zh-CN/`、`/ja/` 输出完整静态页面，`/en/` 保留为英文别名。各语言分别设置元信息、文档入口、下载状态和应用截图，并提供 canonical 与其他语言链接。切换入口在浏览器中记住选择；直接访问语言专属地址时尊重指定语言。


## 默认执行与短等待（当前源码）

普通非交互命令优先使用 `start_task`，交互式终端使用 `start_process`。`start_task.wait_ms` 默认 2,000 毫秒，`get_task_result.wait_ms` 默认 5,000 毫秒，两者均接受 0–10,000；0 表示立即查询。短任务在等待内完成时直接返回状态、退出码与有限输出；仍在运行时返回原任务 ID 和下一步查询参数。等待时长不改变运行时限或幂等身份，断线或取消查询不会取消已登记的任务。终端启动与输出读取每次最多等待 10 秒，结果报告实际等待上限。

## 找回保存的结果（当前源码）

执行记录详情显示结果保存状态，可选择“复制恢复信息”，再在聊天中按其中的原任务或结果引用查询。`get_execution_summary` 也会返回结果引用。普通工具的小结果和大结果均可保存；缓存最多 7 天、独立上限 50 MiB，容量压力下可能提前过期。原生预览保持原格式，结果读取本身不再生成快照。结果可能包含文件正文等用户内容，保存在本机私有目录；读取仍检查当前来源权限。保存失败、过期或旧记录没有快照时会明确说明，不能据此重做写入。
