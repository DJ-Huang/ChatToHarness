# 查看与获取任务产物

[English](../en/artifacts.md) | [简体中文](../zh-CN/artifacts.md) | [日本語](../ja/artifacts.md)

> 适用于 ChatToHarness 0.6.0。

## 使用目标

找到任务真正生成的文件，并确认可读取的结果。

## 开始前

知道任务所属项目和预期输出位置。文件工具只能读取授权范围内的产物。

## 操作步骤

1. 开始任务时说明输出文件应保存在哪里。
2. 结束后要求列出实际存在的产物路径、文件大小和类型。
3. 文本按需分段读取；支持的小图片可以直接预览，大文件可能分段返回。
4. 如果客户端支持附件或下载入口，可从实际返回的文件入口获取；否则在本机文件管理器打开该路径。
5. 重要文件核对内容和大小，保留需要的最终副本。

### 可复制的示例

请将示例路径替换为本机已授权的工程绝对路径；Windows 使用自己的盘符路径。

```text
检查 /Users/demo/ExampleProject/output 中实际生成的文件，列出路径、大小和类型，预览可支持的图片；不要声称不存在的文件已生成。
```

![查看与获取任务产物](../images/help/zh-CN/files.svg)

操作指引示意图，展示操作顺序，不是客户端实际执行结果。

## 完成后的表现

看到的是实际存在且可访问的文件。聊天里的文件名描述不等于已经生成或上传附件。

## 没有成功时

找不到文件时先检查任务是否完成、输出路径是否正确及权限。返回量受限不等于文件损坏；可分段读取或本机打开。应用不保证每种客户端都显示下载按钮。
