# 连接 Codex

[English](../en/codex.md) | [简体中文](../zh-CN/codex.md) | [日本語](../ja/codex.md)

> 适用于 ChatToHarness 0.6.0。

## 使用目标

通过账号实际提供的接入入口，在 Codex 中使用同一个本机工作环境。

## 开始前

本机应用保持运行，通道就绪。账号所属组织已关联该通道。

## 操作步骤

1. 打开当前 Codex 产品支持的 Tunnel 或插件接入入口。入口随产品、账号与版本而异。
2. 选择本机应用管理的同一个 Tunnel，检查组织和使用权限。
3. 完成工具发现后，明确项目绝对路径，先要求查看项目概览。
4. 确认返回实际工具结果，再按首次任务指南测试一个独立文件。

![连接 Codex](../images/help/zh-CN/help.png)

1 客户端接入指引；2 应用更新。 界面演示：使用当前仓库界面与隔离示例数据，不代表真实通道或工具调用成功。

## 完成后的表现

Codex 能实际调用本机工具并返回结果。复用已有通道，无需另外启动一个通道运行程序。

## 没有成功时

没有对应入口时查阅官方指南并联系管理员。不要把托管通道地址直接当普通服务地址填写，也不要照抄未经核实的本地配置。当前文档不将官方支持等同于你的设备已验证。

[OpenAI 官方接入说明](https://developers.openai.com/api/docs/guides/secure-mcp-tunnels)
