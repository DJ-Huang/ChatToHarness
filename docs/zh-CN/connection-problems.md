# 处理连接失败或反复重连

[English](../en/connection-problems.md) | [简体中文](../zh-CN/connection-problems.md) | [日本語](../ja/connection-problems.md)

> 适用于 ChatToHarness 0.6.0。

## 使用目标

区分本机组件、凭据和网络问题，按顺序恢复连接。

## 开始前

打开概览和实时日志，记录当前状态与错误时间。

## 操作步骤

1. 本机工具检查失败：核对安装包和组件，必要时安装匹配的正式版本。
2. 等待系统授权：在系统窗口允许读取已保存凭据；失败时重新输入有效密钥。
3. 认证或权限错误：核对 Tunnel ID、Runtime API Key、组织关联以及 Read + Use 权限。
4. 通道冲突：确认同一通道没有在另一台电脑或另一工具中重复运行。
5. 网络异常：等待自动重连，网络恢复后仍异常再手动重连；需要停止尝试时点击停止。
6. 恢复就绪后，用一次只读客户端调用验证。

## 完成后的表现

日志显示恢复，应用进入通道就绪，随后客户端能实际调用。

## 没有成功时

重连不会重放丢失响应的操作。若问题发生在写入或命令运行期间，先检查执行记录、任务和实际产物，再考虑重试。不要将密钥或完整环境变量发到求助信息中。
