# 更换或清除连接凭据

[English](../en/credentials.md) | [简体中文](../zh-CN/credentials.md) | [日本語](../ja/credentials.md)

> 适用于 ChatToHarness 0.6.0。

## 使用目标

更新运行密钥，或停止使用当前通道的凭据。

## 开始前

在本机应用操作，不把密钥复制到聊天或日志。确认没有需要先检查的执行中操作。

## 操作步骤

1. 打开“连接配置”，核对 Tunnel ID。
2. 更换密钥时在 Runtime API Key 中直接输入新值，再点击“保存并连接”。
3. 保存后输入框清空，界面显示已安全保存；无法回显旧密钥属于正常行为。
4. 如要移除，点击“清除凭据”，确认连接停止。
5. 再次使用时重新填写有效密钥并连接。

![更换或清除连接凭据](../images/help/zh-CN/connection.png)

1 通道标识；2 本机运行密钥；3 保存并连接。 界面演示：使用当前仓库界面与隔离示例数据，不代表真实通道或工具调用成功。

## 完成后的表现

更换后使用新凭据建立连接。清除会停止连接，工作目录和工程规范设置仍保留。

## 没有成功时

系统要求访问凭据时，在系统窗口授权。旧密钥无法解密时可重新填写，不应手动删除整个数据目录。Runtime API Key 与客户端或 API 调用凭据用途不同。
