# 常见问题与如何求助

[English](../en/faq.md) | [简体中文](../zh-CN/faq.md) | [日本語](../ja/faq.md)

> 适用于 ChatToHarness 0.6.0。

## 使用目标

快速解释常见行为，并准备有用的问题报告。

## 开始前

先记录应用版本、电脑系统和大致发生时间。

## 操作步骤

1. 手机能用吗：支持的聊天入口可以远程发起任务，本机电脑和应用仍须保持运行。
2. 关窗口就停止吗：不会；停止连接与退出是独立操作，持久任务还需单独取消。
3. 为什么仍要确认：本机、客户端、系统和外部服务有各自的权限。
4. 需要装开发环境吗：安装包包含运行组件，具体外部工具可能另有要求。
5. 如何求助：在官方仓库 Issues 提交系统、版本、复现步骤、预期与实际结果，以及脱敏后的记录。
6. 提交前检查是否已有相同问题，附最小示例，不附真实密钥或完整私人项目。

![常见问题与如何求助](../images/help/zh-CN/workflow.svg)

操作指引示意图，展示操作顺序，不是客户端实际执行结果。

需要更多工具诊断时，可让客户端只读汇总最近调用、使用情况及当前工具设置。调整工具设置前先核对影响；文件目录授权仍必须在桌面应用修改。内置 Desktop Commander 的反馈入口打开该组件自己的表单，与本产品仓库 Issues 分开。

## 完成后的表现

报告能说明如何复现，以及失败发生在哪个阶段，便于他人定位。

## 没有成功时

没有官方验证过的入口、系统或外部工具，请明确标为未验证。平台权限由对应服务管理；仓库问题报告无法替代管理员授权。
