# 建立第一次连接

[English](../en/first-connection.md) | [简体中文](../zh-CN/first-connection.md) | [日本語](../ja/first-connection.md)

> 适用于 ChatToHarness 0.6.0。

## 使用目标

让本机应用准备好接收客户端的任务。

## 开始前

已安装应用，并准备好 Tunnel ID、Runtime API Key 和试用文件夹。

## 操作步骤

1. 打开“连接配置”，填入 Tunnel ID；客户端稍后也要选择这个通道。
2. 在 Runtime API Key 中输入运行密钥；保存后界面只显示已保存状态。
3. 打开“工作目录”，添加试用文件夹，点击“保存工作目录设置”。
4. 回到“连接配置”，点击“保存并连接”。
5. 如果系统要求访问已保存的凭据，在系统窗口完成授权。
6. 回到“概览”，等待本机工具检查通过并显示“通道就绪”。

![建立第一次连接](../images/help/zh-CN/connection.png)

1 通道标识；2 本机运行密钥；3 保存并连接。 界面演示：使用当前仓库界面与隔离示例数据，不代表真实通道或工具调用成功。

## 完成后的表现

“通道就绪”表示本机可以接收请求。接下来还要在 ChatGPT 或 Codex 选择同一通道，并完成一次实际调用。

## 没有成功时

连接异常时先核对组织、通道 ID 和密钥权限，再查看日志。使用同一个通道时，只保留一个本机运行实例；不要在其他工具中另外启动该通道。
