# 安装受阻或无法启动

[English](../en/installation-problems.md) | [简体中文](../zh-CN/installation-problems.md) | [日本語](../ja/installation-problems.md)

> 适用于 ChatToHarness 0.6.0。

## 使用目标

从下载来源、系统条件和提示内容定位安装问题。

## 开始前

保留系统提示截图和下载文件名，先不要删除已有配置。

## 操作步骤

1. 核对系统：Apple 芯片 Mac 的 macOS 14+，或 Windows 11 x64。
2. 确认安装包来自官方 GitHub Release，文件名和 SHA-256 校验值与该版本一致。
3. Mac 将应用放到“应用程序”后启动；系统提示未公证时，核对来源后按系统安全设置处理。
4. Windows 若出现信誉或签名提示，先查看该 Release 的未签名说明并核对文件，不要使用未知来源副本。
5. 首次运行所需组件不可用时，重新下载安装匹配版本；保留错误信息用于求助。

![安装受阻或无法启动](../images/help/zh-CN/install.svg)

操作指引示意图，展示操作顺序，不是客户端实际执行结果。

## 完成后的表现

来源、版本和系统条件已核实，能够打开控制台或得到明确的阻断原因。

## 没有成功时

不要为绕过一个安装提示而关闭整个系统保护。已有应用无法启动时，可先使用托盘恢复窗口，避免把后台运行误认为未启动；重新安装不要求先删除个人数据。
