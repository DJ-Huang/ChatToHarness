# ChatToHarness 能做什么

[English](../en/introduction.md) | [简体中文](../zh-CN/introduction.md) | [日本語](../ja/introduction.md)

> 适用于 ChatToHarness 0.6.0。

## 使用目标

在熟悉的 AI 对话中处理电脑上的文件和任务。

## 开始前

准备一台支持的电脑，以及可使用 Tunnel 接入的 ChatGPT 或 Codex 账号。

## 操作步骤

1. 在电脑上运行 ChatToHarness，管理连接、工作目录和工具。
2. 在客户端用自然语言描述任务，说明要处理的文件夹。
3. 需要时连接第三方工具服务；在本机选择允许它提供哪些能力。
4. 回到应用查看连接状态、实时日志与执行记录。

![ChatToHarness 能做什么](../images/help/zh-CN/overview.png)

1 连接状态；2 功能入口；3 首次调用步骤。 界面演示：使用当前仓库界面与隔离示例数据，不代表真实通道或工具调用成功。

## 完成后的表现

文件和命令在运行 ChatToHarness 的电脑上处理；结果通过客户端返回。文件、终端和扩展工具的可用性取决于你的配置。

## 没有成功时

手机可以作为支持的聊天入口，本机电脑仍须开机并保持应用运行。应用没有内置通用鼠标键盘自动化；某项外部工具的能力由该服务决定。
