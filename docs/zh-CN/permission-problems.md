# 处理目录、密钥或工具授权失败

[English](../en/permission-problems.md) | [简体中文](../zh-CN/permission-problems.md) | [日本語](../ja/permission-problems.md)

> 适用于 ChatToHarness 0.6.0。

## 使用目标

找出是哪一层权限阻止操作，并在对应位置处理。

## 开始前

保留具体错误提示，区分应用、本机系统、第三方服务和客户端的确认。

## 操作步骤

1. 目录拒绝：在“工作目录”添加目标并保存，核对绝对路径与链接的真实目标。
2. 凭据读取失败：处理系统授权窗口，必要时在应用重新填写密钥。
3. 第三方认证失败：检查该服务自己的环境变量或请求头密钥。
4. 工具禁用或等待信任：在 MCP Servers 核对来源，完成信任并设置工具权限。
5. 本机确认过期：检查请求是否尚未执行，核对目标后再发起新请求，并及时在应用确认。
6. ChatGPT 仍要求确认：这是独立的客户端权限，请在客户端核对处理。

## 完成后的表现

只调整与当前操作有关的权限，并再次用合适的只读调用核验。

## 没有成功时

没有项目范围的调用可能无法记住项目授权；配置或工具变化后可能需要重新确认。不要让聊天工具直接改目录白名单，也不要为了单次失败而开放所有个人文件。
