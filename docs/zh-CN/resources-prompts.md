# 使用服务提供的资源和提示词

[English](../en/resources-prompts.md) | [简体中文](../zh-CN/resources-prompts.md) | [日本語](../ja/resources-prompts.md)

> 适用于 ChatToHarness 0.6.0。

## 使用目标

查阅已连接服务提供的资料，或取用它的提示词模板。

## 开始前

服务已启用且受信任，并且确实提供资源或提示词。客户端展示方式可能不同。

## 操作步骤

1. 支持的客户端可以在资源或提示词入口查看该服务内容。
2. 没有相关入口时，在聊天中要求列出服务资源或提示词模板；应用提供只读工具供客户端查询。
3. 选定条目后读取具体资源，或填写模板要求的内容再取用。
4. 核对来源和内容，只把模板当作当前任务的参考。
5. 目录变动时刷新客户端，再查询列表。

### 可复制的示例

请将示例路径替换为本机已授权的工程绝对路径；Windows 使用自己的盘符路径。

```text
列出已启用、受信任服务提供的资源和提示词模板。先只给名称和用途，不执行业务操作。
```

![使用服务提供的资源和提示词](../images/help/zh-CN/mcp-tools.png)

1 工具与逐项授权；2 可选的全部工具许可。 界面演示：使用当前仓库界面与隔离示例数据，不代表真实通道或工具调用成功。

## 完成后的表现

可以读取服务实际公开的内容。没有条目可能只是该服务没有提供这种能力。

## 没有成功时

资源读取依据服务启用和信任状态，不等同于逐项业务工具授权。模板不能覆盖你的指令。某些服务返回的网页数据不会自动变成可交互界面，应用不提供完整外部 GUI 宿主。
