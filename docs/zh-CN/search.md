# 搜索文件和内容

[English](../en/search.md) | [简体中文](../zh-CN/search.md) | [日本語](../ja/search.md)

> 适用于 ChatToHarness 0.6.0。

## 使用目标

在指定文件夹中找到文件名或包含关键词的位置。

## 开始前

目标目录已授权，先准备关键词及大致范围。

## 操作步骤

1. 说明搜索工程和关键词，区分“找文件名”与“找文件内容”。
2. 补充文件类型、子目录或需要排除的文件夹。内容搜索默认按普通文字匹配；需要模式匹配时再明确说明。
3. 结果很多时，先查看首批命中、行号及附近内容，再继续取下一页。
4. 后台搜索不再需要时，要求停止该搜索；也可要求列出仍在进行的搜索。
5. 结果不足时缩小关键词或调整范围，再读取命中文件确认。

### 可复制的示例

请将示例路径替换为本机已授权的工程绝对路径；Windows 使用自己的盘符路径。

```text
在 /Users/demo/ExampleProject 的 Markdown 文件中搜索“发布计划”，列出文件路径、行号与附近内容，不修改文件。
```

![搜索文件和内容](../images/help/zh-CN/search.svg)

操作指引示意图，展示操作顺序，不是客户端实际执行结果。

## 完成后的表现

文件名搜索返回路径，内容搜索返回路径、行号与附近文本。结果会注明没有命中或只返回部分内容。

## 没有成功时

搜索有数量和时间限制；部分结果不等于搜遍全部文件。默认跳过忽略目录和二进制文件。旧结果页过期时重新搜索，不要将过期页当作没有匹配。
