## 中文

ChatToHarness 将 AI 对话连接到本机执行环境。

- 全新中文、英文、日文控制台与官网，可即时切换并记住语言。
- 通过安全通道接入 ChatGPT、Codex，使用本机文件、终端、Git 和开发命令。
- 自动交付 AGENTS.md 与相关工程规则，按工程、范围和版本隔离上下文。
- 菜单栏／托盘常驻，支持后台运行、连接恢复及受管进程回收。
- 凭据由系统加密保存，工具进程不接收 Runtime API Key；保留原 LocalHarness 配置兼容。
- 三语使用说明、真实界面截图、新 Logo，以及自动构建、校验、正式发布和官网更新。

系统要求：Windows 11 x64；macOS 14+ Apple Silicon。目录设置不构成终端沙箱，命令按当前用户权限执行。请参阅本页签名状态。

## English

ChatToHarness connects AI chat to your local execution environment.

- A redesigned console and website in English, Simplified Chinese, and Japanese, with instant switching and remembered choices.
- Secure tunnel access for ChatGPT and Codex to local files, terminals, Git, and development commands.
- Automatic AGENTS.md and project-rule delivery, with context isolated by project, scope, and content version.
- Menu bar/system tray operation, background connections, reconnection, and managed-process cleanup.
- System-encrypted credentials, Runtime API Key isolation from tool processes, and compatibility with existing LocalHarness settings.
- Three-language guides, real interface screenshots, a new logo, and automated builds, checksum verification, public releases, and website updates.

Requirements: Windows 11 x64; macOS 14+ Apple Silicon. Directory settings do not sandbox the terminal; commands run with your user permissions. See the signing status on this page.

## 日本語

ChatToHarness は AI チャットをローカルの実行環境につなぎます。

- 日本語・英語・中国語の新しいコンソールとサイト。言語を即座に切り替え、選択を記憶します。
- 安全なトンネルで ChatGPT・Codex からローカルのファイル、ターミナル、Git、開発コマンドを利用できます。
- AGENTS.md と工程規約を自動で提供し、工程・範囲・内容の版ごとにコンテキストを分離します。
- メニューバー／トレイ常駐、バックグラウンド接続、再接続、管理対象プロセスの回収に対応します。
- システム暗号化による認証情報保存、ツールへの Runtime API Key の隔離、既存 LocalHarness 設定との互換性を維持します。
- 3言語のガイド、実画面の画像、新ロゴ、自動ビルド・チェックサム確認・正式公開・サイト更新を提供します。

対象：Windows 11 x64、macOS 14+ Apple Silicon。フォルダー設定はターミナルを隔離しません。コマンドは現在のユーザー権限で実行されます。署名状態は本ページを確認してください。
