## 中文

- 新增应用级 MCP 网关与 **MCP Servers** 管理页面，支持 stdio、Streamable HTTP、Mac／Windows 配置覆盖、连接测试、状态与工具预览。
- 支持本应用格式和常见 `mcpServers` JSON 的预览导入与导出。导入服务默认禁用；导出不含密钥值、信任记录或工具授权。
- 新增逐工具禁用、直接调用、每次本机确认三种策略。新工具默认禁用，定义变化后重新授权；内置工具保留原名称，第三方工具使用 `serverId__toolName`。
- 为第三方服务隔离环境变量，支持结构化结果与图片，限制调用时长和消息大小；传输中断后独立重连，不自动重放调用。
- 修复新增 `AGENTS.md` 在目录元数据未变化时未被发现的问题，确保工程规范变化后旧上下文失效。
- 改善 Windows 子进程退出后的清理稳定性，修复 macOS PR 构建签名处理；MCP 握手统一报告实际应用版本。
- 官网首次访问默认英文，保留中日文页面及 `/en/` 兼容地址；三语 README 新增展示图，并增加发布后官网版本与下载链接验证。

升级提示：在 MCP Servers 中配置、信任并启用所需服务，授权工具后按需刷新 ChatGPT 插件工具目录。第三方服务按当前用户权限运行；远程 HTTP 服务要求 HTTPS，HTTP 仅允许回环地址。本版支持静态请求头认证，不支持 OAuth 或旧式 HTTP+SSE；目前聚合工具，不提供资源／提示词浏览。真实客户端能否使用新工具仍取决于客户端发现与调用结果。

## English

- Add an application-owned MCP gateway and **MCP Servers** management page with stdio, Streamable HTTP, Mac/Windows configuration overrides, connection checks, status, and tool previews.
- Preview and import the application format or common `mcpServers` JSON, and export configurations. Imported servers start disabled; exports omit secret values, trust records, and tool grants.
- Add per-tool deny, allow, and local-confirmation policies. New tools start denied, and changed definitions require fresh authorization. Built-in tool names remain unchanged; third-party tools use `serverId__toolName`.
- Isolate third-party service environments, support structured results and images, and bound call duration and message size. Transport recovery reconnects independently without replaying calls.
- Detect newly added `AGENTS.md` files even when directory metadata remains unchanged, invalidating previously delivered project context.
- Improve cleanup after Windows child-process exit and correct macOS PR-build signing behavior. MCP handshakes now report the actual application version.
- Default the website to English on first visit while retaining saved language choices, Chinese, Japanese, and the `/en/` alias. Add a hero image to all three READMEs and verify the production website version and download links after release.

Upgrade notes: configure, trust, and enable the required servers in MCP Servers, authorize their tools, and refresh the ChatGPT plugin tool list when needed. Third-party services run with your user permissions. Remote HTTP endpoints require HTTPS; plain HTTP is limited to loopback. This release supports static authentication headers, not OAuth or legacy HTTP+SSE, and aggregates tools without resource or prompt browsing. Availability in a real client depends on successful discovery and invocation.

## 日本語

- アプリ管理の MCP ゲートウェイと **MCP Servers** 画面を追加しました。stdio、Streamable HTTP、Mac／Windows 別設定、接続テスト、状態表示、ツールのプレビューに対応します。
- アプリ独自形式と一般的な `mcpServers` JSON のプレビュー付きインポート、および設定のエクスポートに対応します。読み込んだサーバーは無効状態で追加され、エクスポートには秘密値、信頼記録、ツール許可を含めません。
- ツールごとに無効、直接実行、毎回のローカル確認を設定できます。新しいツールは既定で無効となり、定義変更後は再許可が必要です。内蔵ツール名は維持し、外部ツールには `serverId__toolName` を使用します。
- 外部サービスの環境変数を分離し、構造化結果と画像、呼び出し時間とメッセージ容量の上限に対応します。通信障害時は個別に再接続し、呼び出しを自動再実行しません。
- ディレクトリのメタ情報が変わらない場合でも、新規の `AGENTS.md` を検出し、以前に提供したプロジェクトコンテキストを無効化します。
- Windows 子プロセス終了後の後処理を安定化し、macOS の PR ビルドでの署名処理を修正しました。MCP ハンドシェイクには実際のアプリバージョンを使用します。
- サイトへの初回アクセスは英語を既定とし、中国語・日本語ページと `/en/` の互換 URL を維持します。三言語の README に紹介画像を追加し、公開後のサイトバージョンとダウンロードリンクを検証します。

更新時の注意：MCP Servers で必要なサーバーを設定・信頼・有効化し、ツールを許可した後、必要に応じて ChatGPT プラグインのツール一覧を更新してください。外部サービスは現在のユーザー権限で実行します。リモート接続には HTTPS が必須で、HTTP はループバックのみ許可します。本版は固定認証ヘッダーに対応し、OAuth と旧式 HTTP+SSE には対応しません。集約対象はツールで、リソースやプロンプトの閲覧は提供しません。実クライアントでの利用可否は検出と呼び出しの結果に依存します。
