## 中文

### 主要更新

- **更完整的本机 Harness**：新增 `get_harness_status`、`get_project_overview`、Git 只读检查及工程规范/Rules/Skills 按需发现，便于在 ChatGPT 中理解项目、确认设备与运行版本。
- **持久任务与恢复**：提供后台任务启动、状态/结果/日志读取、取消及稳定的幂等键。断线、超时或应用重启后优先查询原任务，执行结果未知时**不会自动重放命令**。
- **MCP 扩展与权限**：优化 Desktop Commander 兼容性，支持第三方 MCP Resources/Prompts、结构化与图片结果保真、项目/工具授权记忆及可选的“允许所有工具”。仅对已启用且受信任的服务生效，ChatGPT 平台权限仍独立管理。
- **执行记录与实时日志**：App 内新增执行历史、错误筛选、搜索、复制及导出；首页和侧边栏提供每 2 秒增量刷新的实时日志，支持暂停、自动滚动和过滤。日志与执行记录归为可折叠菜单，默认收起子项。
- **容量与诊断保护**：默认最多保留 7 天/10,000 条执行记录，可清理日志共享 50 MiB 预算；单个后台任务输出最多 4 MiB。详细诊断须手动开启，30 分钟后自动关闭；默认只保存脱敏摘要。
- **Mac / Windows 稳定性**：改进应用实例、Tunnel/MCP 工具目录刷新、跨平台子进程管理和安全文本编辑；继续使用隔离配置与合成数据进行发布验收。

### 升级与安全提示

原有本机配置保留。切换实例或版本可能中断当前 MCP Session；如果写操作超时，先查询任务状态和实际产物，避免重复执行。执行完成、结果写入本机传输通道与 ChatGPT 最终收到结果是不同状态，未获得客户端确认时显示“未知”。

本版默认安装包 **Windows 未签名；macOS 为临时签名且未公证**，系统可能提示安全警告。请仅从本仓库 GitHub Release 下载并核对 `SHA256SUMS.txt`。

### 已知限制与升级提示

- 持久后台任务不会因为桌面 App Stop／Quit 就必然停止；升级前如需停止，请显式取消并确认任务终态。日志视图不是无损审计流，任务身份与防重放记录也不计入 50 MiB 日志预算。
- 对资源／提示词的支持是原生协议和只读工具回退；不提供资源订阅、completion、sampling、elicitation，第三方工具结果中的任意资源链接并不保证透明改写。
- v0.6.0 发布包、签名与 SHA256SUMS 尚待标签工作流完成确认；本说明目前仅随发布准备分支提交，并非公开 Release 已发布。

## English

### Highlights

- **Stronger local Harness context**: add `get_harness_status`, `get_project_overview`, read-only Git inspection, and on-demand project AGENTS/Rules/Skills discovery.
- **Durable tasks and recovery**: background start/status/results/paginated logs/cancellation with stable idempotency keys. Reconnects, timeouts, and process restarts do **not** automatically replay potentially executed mutations.
- **MCP integration and access controls**: improve Desktop Commander compatibility, preserve native MCP resources/prompts and structured/image results, remember tool/project grants, and provide an optional global allow-all switch for **enabled, trusted** services. ChatGPT-side approvals remain independent.
- **Execution history and live logs**: searchable, filterable and exportable execution records; a live log viewer with incremental refresh, pause, follow and quick filters. The log sidebar group starts collapsed and expands to reveal execution history.
- **Bounded diagnostics**: default retention of up to seven days and 10,000 execution records, a shared 50 MiB cleanable-log budget, and up to 4 MiB output per background task. Detailed diagnostics are opt-in and stop automatically after 30 minutes; ordinary records use redacted summaries.
- **Mac and Windows reliability**: improve session continuity, MCP catalog refreshes, cross-platform process supervision and recoverable text edits. Release acceptance uses isolated profiles and synthetic fixtures.

### Upgrade and security notes

Saved local settings are preserved. Switching application versions may interrupt the active MCP session; after a timeout, inspect saved task state and artifacts before repeating a mutation. A successful local transport write does **not** prove the ChatGPT client received the response.

Default installers: **unsigned Windows binary; ad-hoc-signed, non-notarized macOS app**. Operating systems may warn or block installation. Download only from this repository's GitHub Release and verify `SHA256SUMS.txt`.

### Known limits and upgrade reminders

- Durable workers may outlive desktop Stop/Quit; explicitly cancel and confirm task completion when needed before replacing the app. The rolling log viewer is not a lossless audit stream, and task identities/replay guards are not covered by the 50 MiB cleanable-log budget.
- Native and fallback resource/prompt reads do not imply subscriptions, completion, sampling, elicitation, or transparent rewriting of every resource link embedded in upstream tool results.
- The v0.6.0 binaries, signing state, and public SHA256SUMS must be confirmed by the future tag workflow. These are prepared notes, not proof of a published Release.

## 日本語

### 主な変更点

- **ローカル Harness の強化**：`get_harness_status`、`get_project_overview`、Git の読み取り専用確認、AGENTS／Rules／Skills のオンデマンド検出を追加しました。
- **永続タスクと復旧**：バックグラウンド実行、状態・結果・ページ分割ログの取得、キャンセル、安定した冪等キーに対応します。切断・タイムアウト・再起動後も、実行済みの可能性がある操作を**自動的に再実行しません**。
- **MCP の拡張と権限管理**：Desktop Commander との互換性、MCP Resources／Prompts、構造化データと画像の保持、ツール／プロジェクト単位の権限記憶を改善しました。全ツール許可は有効で信頼済みのサービスだけに適用され、ChatGPT 側の確認とは独立しています。
- **実行履歴とリアルタイムログ**：検索・フィルター・エクスポートができる実行履歴と、増分更新・一時停止・自動スクロールができるログ画面を追加しました。サイドバーのログ配下メニューは既定で折りたたまれます。
- **ログ容量と診断の制御**：既定で最大 7 日／10,000 件、共有ログ予算 50 MiB、タスク出力 4 MiB に制限します。詳細診断は手動で有効化し、30 分後に自動停止します。通常の履歴は機密情報を伏せた概要を保存します。
- **Mac／Windows の安定性**：MCP セッション、ツール一覧更新、プロセス管理、復旧可能なテキスト編集を改善し、一時プロファイルと合成データで検証します。

### 更新時の注意

保存済みのローカル設定は維持されます。アプリの切り替えによって MCP セッションが途切れる場合があります。タイムアウト後は、同じ変更を繰り返す前にタスク状態や生成物を確認してください。ローカル伝送への書き込み成功は ChatGPT での受信確認ではありません。

既定のインストーラーは **Windows 未署名／macOS アドホック署名・未公証** です。OS による警告や制限が発生する可能性があります。本リポジトリの GitHub Release からのみ取得し、`SHA256SUMS.txt` を照合してください。

### 制約とアップグレード時の注意

- 永続 worker はデスクトップの Stop／Quit 後も実行される場合があります。アップグレード前に必要なら明示的にキャンセルして終了状態を確認してください。ログのスクロール表示は無損失の監査記録ではなく、タスク ID／再実行防止データは 50 MiB のログ枠に含まれません。
- ネイティブ／フォールバックのリソース・プロンプト取得は購読、completion、sampling、elicitation、あらゆるツール結果内リンクの透過的書換えを保証しません。
- v0.6.0 のインストーラー、署名状態、公開 SHA256SUMS はタグ実行時に確認します。これは準備中のリリースノートであり、公開済みの証拠ではありません。
