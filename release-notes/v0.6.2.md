# ChatToHarness 0.6.2

## 简体中文

- 改进持久任务恢复：短任务可直接返回完成结果，运行中的任务返回原任务 ID 和后续查询参数；幂等冲突引导检查原任务，避免重复执行。
- 保存工具结果供断连后恢复，执行记录提供结果引用与恢复信息；日志支持游标分页和最近内容查询，保留真实退出码与明确错误。
- 改进连接恢复、诊断查询与 Windows 原子记录写入的可靠性。
- 修复发布后官网部署流程：从 main 部署并等待线上版本和下载链接校验。
- 更新后请刷新或重新连接客户端插件，以获取最新工具列表。结果缓存有时间和容量限制；超时后请先查询原任务，不要直接重复写入。

## English

- Improve persistent task recovery: short tasks can return completed results directly; active tasks return the original task ID and next query arguments. Idempotency conflicts direct clients to inspect the original task rather than duplicate execution.
- Save tool results for recovery after disconnects, with result references and recovery information in execution history. Add cursor pagination and tail queries for logs, preserving actual exit codes and explicit errors.
- Improve connection recovery, diagnostic queries and atomic record writes on Windows.
- Fix release website delivery: deploy from main and wait for production version and download-link verification.
- Refresh or reconnect the client plugin after upgrading to load the latest tools. Result caching has age and capacity limits; inspect the original task before retrying a timed-out write.

## 日本語

- 永続タスクの復旧を改善。短いタスクは完了結果を直接返し、実行中のタスクは元のタスク ID と次の照会引数を返します。冪等性の競合時は、重複実行せず元のタスクを確認するよう案内します。
- 切断後に復旧できるようツール結果を保存し、実行履歴に結果参照と復旧情報を追加しました。ログのカーソルページングと末尾照会に対応し、実際の終了コードと明確なエラーを保持します。
- 接続復旧、診断照会、Windows のアトミックな記録更新の信頼性を改善しました。
- リリース後の Web サイト配信を修正。main から配信し、本番のバージョンとダウンロードリンクの検証完了を待ちます。
- 更新後はクライアントのプラグインを更新または再接続してください。結果キャッシュには保存期間と容量の上限があります。書き込みがタイムアウトした場合は、再実行する前に元のタスクを確認してください。
