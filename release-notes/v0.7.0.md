## 中文

### 0.7.0 主要更新

- **macOS Computer Use（开发预览）**：新增原生窗口枚举、单窗口截图、经授权的鼠标/键盘/滚动操作、会话与截图防重放，以及 Esc/STOP 安全终止机制。macOS 系统需分别授予屏幕录制和辅助功能权限。
- **真实指针运动**：Mac 与 Windows 的鼠标操作改为约 60 Hz、按移动距离调节耗时的系统指针运动；跨屏时沿实际显示器边界规划路径。
- **构建与权限诊断**：macOS 原生 helper 随应用打包，提供权限状态检查；修复原生 helper 经 ad-hoc 签名后的资源完整性校验。
- **更新器兼容**：应用内更新逻辑可识别本机安装的预发布版本，并继续以稳定 GitHub Release 为升级目标。

### 升级和安全注意

这是本地生成的 macOS arm64 `0.7.0` 安装包，**并未创建 Git Tag、推送远端或公开发布 GitHub Release**。应用采用临时（ad-hoc）签名、未经过 Apple 公证，macOS 可能提示安全风险。升级前注意现有会话与系统辅助功能授权可能需要重新确认。

### 已知限制

- macOS Computer Use 的组合快捷键（例如 Command+A）、STOP 按钮的 GUI 实测、鼠标 Glow 视觉效果、多显示器实际操作和正式签名/公证尚未完成全部验收。
- Windows 真实鼠标轨迹的视觉验收尚未执行。
- 此文档仅描述本地构建的版本内容，不代表产品已在 GitHub 正式发布。

## English

### 0.7.0 highlights

- **macOS Computer Use (development preview)**: native window enumeration, single-window screenshots, authorized mouse/keyboard/scroll actions, single-use observation protections, and Esc/STOP safeguards. Screen Recording and Accessibility permissions are required.
- **Human-paced real cursor**: distance-dependent, approximately 60 Hz physical cursor movement on Mac and Windows, including monitor-aware paths.
- **Build and permissions**: packaged macOS helper, permission diagnostics, and post-signing resource verification.
- **Updater compatibility**: support comparing a locally installed prerelease with a stable GitHub Release.

### Install notes and limitations

The local macOS arm64 0.7.0 installer is ad-hoc-signed and not Apple-notarized. No Git tag, push, or public GitHub Release has been created. Some Computer Use features (modifier shortcuts, GUI STOP, Glow visual quality, full monitor acceptance) remain under verification. Windows GUI visual acceptance is also pending.
