# ChatToHarness 0.7.2

## 中文

### 主要更新

- **macOS Computer Use HUD 可读性**：使用深海军蓝高对比度底板取代受壁纸和系统材质影响的浅色效果。标题、会话 ID 和操作状态文字的颜色分别优化；保留红色 STOP / Esc 控件。
- **动态 cyan 边框**：基础圆角边框叠加高亮移动光头及柔和拖尾，每 3.5 秒沿完整边框匀速循环。HUD 尺寸变化时自动重绘路径。
- **Computer Use 默认真实交互**：仓库新增 `docs/computer-use-policy.md` 及根目录 `AGENTS.md`。工具描述提示默认使用真实鼠标、键盘，不得擅自改为系统窗口定位 API。
- **多设备会话优先**：工具描述及路由规则优先级为「用户明确指定 > 当前 ChatGPT 会话可信关联设备 > 唯一可用设备 > 编号 1/2/3 供用户选择」。内部设备 UUID 无需用户填写。

### 安装与已知限制

- 本地 **macOS Apple Silicon（arm64）** DMG 安装包，ad-hoc 签名，**未经 Apple 公证**。未替换运行中应用，也未创建 GitHub Release。
- macOS 原生鼠标跨显示器真实拖动此前已通过一次实机验收。新的 HUD 动画通过了 AppKit/CA 图层测试，但用户桌面实际视觉效果仍须安装新构建后验收。
- 设备路由的测试接口与工具指引已实现，但跨 ChatGPT 连接的可信会话绑定尚未由 ChatGPT 客户端集成；任意命令执行工具也未被技术性限制调用 OS API。
- 本次只验证 macOS；不能据此宣称 Windows 原生 UI 通过验收。

## English

- Readable high-contrast macOS Computer Use HUD with a dark backplate, legible title/session/activity text, and retained red STOP/Esc control.
- A smooth continuous cyan head-and-trail perimeter animation, completing a circuit every 3.5 seconds and adapting to HUD resizing.
- Canonical Computer Use policy and AGENTS guidance favor visible native mouse/keyboard input over silent OS window-position API substitution.
- Device routing preference: explicit user target, trusted current-chat device, sole connected device, otherwise numbered choices.
- Local macOS arm64 installer is ad-hoc signed, not notarized. ChatGPT-hosted session router enforcement and real Windows GUI validation remain out of scope.
