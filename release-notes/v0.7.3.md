# ChatToHarness 0.7.3 — macOS Computer Use 窗口拖动可靠性修复

## 修复

- CU_TARGET_OCCLUDED 报告遮挡窗口 ID、进程、层级、透明度及边界；结合 macOS Accessibility 命中检测减少纯矩形误判，未知场景继续拒绝，不泄漏其它窗口标题。
- 新增 Mac 专用 drag_window：一次已授权调用内由真实鼠标完成移动、按下、拖动和释放，解决跨调用 30 秒按键保护导致的 CU_MOUSE_NOT_HELD。
- 拖动开始前最多检测 3 个标题栏候选点，切换落点时自动补偿终点；不重放状态不确定的动作。
- observe 返回 window_bounds，便于 Quartz 多屏精准计算；继续要求窗口身份、前台、截图时效、Esc/STOP 和 close_session。
- Windows 公开 Computer Use 操作保持不变。

## 已验证

- macOS 真实临时 AppKit 窗口主屏拖动和第二屏跨屏拖动；目标 (-1624,-904) 与实测完全吻合。
- 原生 Swift 编译、npm test 388 项（379 通过、9 跳过、0 失败），Esc 紧急停止及退出会话通过。
- 安装包构建不主动替换当前用户正在运行的 0.7.2 程序。

## 限制

Mac arm64 DMG 将采用本地临时 ad-hoc 签名，未经 Apple 公证。仍需在实际安装升级后验证 ChatGPT 对新工具的发现、ChatToHarness 主窗口跨屏移动。Command+A、STOP 控件人工点击及鼠标 Glow 人眼视觉验收另行保留。
