# ChatToHarness 0.8.0

## 简体中文

- 新增 Windows x64 与 macOS arm64 内置 Computer Use 实验功能：在明确授权的窗口内观察截图，执行真实鼠标、键盘、滚动和窗口拖动。保留本机窗口授权、用户接管检测及 STOP / Esc 停止。
- 增加跨平台 GUI 任务接口、进度检查点及恢复状态；结合新鲜截图提交后续决策，不自动重放结果未知的输入。HUD 展示任务和操作状态；真实聊天标题仅在宿主提供可信元数据时显示。
- 统一插件管理：内置 Computer Use 与外部 MCP 服务共用一个列表，通过右侧管理抽屉配置连接、信任、工具及项目权限；添加插件、导入配置和全局插件设置使用明确入口。
- 修复插件抽屉遮挡本机调用确认的问题；编辑中的连接配置不会被后台刷新覆盖，关闭管理面板时清除未保存的敏感输入。macOS 开发入口使用独立应用标识与权限说明。
- 改进帮助中心构建：支持任意数量及顺序的章节，保留标准章节的旧链接，为自定义或重复标题生成独立链接；同步三语插件说明和升级后客户端刷新指引。

升级提示：安装后，请在 ChatGPT / Codex 等客户端刷新工具列表或重新连接 Harness；仅重启桌面应用不保证客户端更新缓存。Computer Use 首次使用时默认关闭，已保存的启用状态会继续沿用。需要启用时，在“插件 → Computer Use → 管理”中检查权限并主动开启。macOS 需要屏幕录制与辅助功能权限，升级或更换开发/安装入口后可能需要重新确认。已有 MCP 连接与授权配置继续沿用。

能力边界：Computer Use 仍是实验功能。Windows 偶发指针回跳问题尚未确认修复；部分 macOS 点击、遮挡和跨屏场景仍需后续验证。没有可用的可信 Planner 时，GUI 任务等待客户端提交决策；实际客户端的异步 MCP Sampling 支持尚未完成端到端确认。宿主不提供真实聊天标题时显示不可获取，不推测或伪造。CI 与隔离窗口验收不代表任意应用和桌面任务均已验证。

版本说明：上一正式版本为 v0.6.2。仓库中的 v0.7.0–v0.7.3 记录来自本地开发安装包，本次统一以 v0.8.0 正式发布，便于这些本地版本正常升级。

## English

- Add an optional built-in Computer Use experimental feature for Windows x64 and macOS arm64: observe screenshots and perform real mouse, keyboard, scrolling and window-drag input within explicitly authorized windows. Local window consent, user takeover detection and STOP / Esc remain enforced.
- Add cross-platform GUI task APIs, progress checkpoints and recovery states. Submit subsequent decisions against fresh observations without automatically replaying inputs with unknown outcomes. The HUD shows task and action status; a real conversation title is displayed only when the host supplies trusted metadata.
- Unify plugin management: built-in Computer Use and external MCP services share one list, with a right-side management drawer for connections, trust, tools and project permissions. Adding plugins, importing configuration and changing global plugin settings have dedicated entry points.
- Fix local approval controls being hidden behind the plugin drawer. Background refresh preserves connection drafts, and closing the drawer clears unsaved sensitive inputs. The macOS development entry uses a separate app identity and permission descriptions.
- Improve help-center generation: allow any number and order of sections, retain existing links for standard headings, and generate distinct links for custom or repeated headings. Update the three-language plugin guides and client-refresh instructions.

Upgrading: refresh the tool list or reconnect Harness in clients such as ChatGPT / Codex after installation; restarting the desktop app alone does not guarantee refreshed client caches. Computer Use is off on first use, while an existing saved enablement setting is preserved. To enable it, inspect permissions and explicitly turn it on under Plugins → Computer Use → Manage. macOS requires Screen Recording and Accessibility permissions, which may need confirmation after upgrading or changing the development/installed entry point. Existing MCP connections and authorization settings remain in use.

Scope: Computer Use remains experimental. Intermittent pointer snapback on Windows remains under investigation; some macOS click, occlusion and multi-display scenarios still need follow-up validation. Without an available trusted Planner, GUI tasks wait for client-submitted decisions; asynchronous MCP Sampling support in actual clients is not yet verified end to end. A missing host-provided conversation title is shown as unavailable rather than guessed. CI and isolated-window acceptance do not establish compatibility with every application or desktop task.

Versioning: the previous public release is v0.6.2. The v0.7.0–v0.7.3 records in this repository describe local development installers. This public release uses v0.8.0 so those local builds can upgrade normally.

## 日本語

- Windows x64 と macOS arm64 向けに、任意で有効にする内蔵 Computer Use 実験機能を追加しました。明示的に許可したウィンドウ内でスクリーンショットを確認し、実際のマウス、キーボード、スクロール、ウィンドウドラッグを実行します。ローカルのウィンドウ許可、ユーザー操作の検知、STOP / Esc による停止を維持します。
- 共通の GUI タスク API、進捗チェックポイント、復旧状態を追加しました。新しい観測に基づいて次の判断を送信し、結果が不明な入力を自動で再実行しません。HUD にタスクと操作状態を表示し、実際の会話タイトルはホストが信頼できるメタデータを提供した場合にのみ表示します。
- プラグイン管理を統合しました。内蔵 Computer Use と外部 MCP サービスを同じ一覧に表示し、右側の管理パネルで接続、信頼、ツール、プロジェクト権限を設定します。追加、設定のインポート、全体設定にそれぞれ専用の入口を用意しました。
- プラグインの管理パネルにローカル承認ボタンが隠れる問題を修正しました。バックグラウンド更新で編集中の接続設定を上書きせず、パネルを閉じると未保存の機密入力を消去します。macOS の開発用起動には独立したアプリ識別子と権限説明を使用します。
- ヘルプセンターの生成を改善しました。章の数と順序を自由にし、標準見出しの既存リンクを維持しつつ、独自または重複する見出しには個別リンクを生成します。三言語のプラグイン説明と更新後のクライアント再接続手順も更新しました。

更新時の注意：インストール後は、ChatGPT / Codex などのクライアントでツール一覧を更新するか、Harness に再接続してください。デスクトップアプリの再起動だけではクライアントのキャッシュ更新を保証できません。Computer Use は初回利用時に無効で、保存済みの有効・無効設定は引き継がれます。有効にする場合は「プラグイン → Computer Use → 管理」で権限を確認し、明示的に切り替えてください。macOS では画面収録とアクセシビリティの権限が必要で、更新や開発版・インストール版の切り替え後に再確認が必要になる場合があります。既存の MCP 接続と許可設定は引き続き使用します。

制限：Computer Use は実験機能です。Windows でまれに発生するポインターの跳ね戻りは引き続き調査中です。macOS の一部のクリック、遮蔽、複数画面の場面には追加検証が必要です。利用可能な信頼できる Planner がない場合、GUI タスクはクライアントからの判断を待ちます。実際のクライアントにおける非同期 MCP Sampling のエンドツーエンド対応は未確認です。ホストから実際の会話タイトルが提供されない場合は取得不可と表示し、推測しません。CI と隔離ウィンドウでの検証は、すべてのアプリやデスクトップ操作の動作保証ではありません。

バージョンについて：前の公開版は v0.6.2 です。リポジトリ内の v0.7.0–v0.7.3 の記録はローカル開発用インストーラーのものです。それらから正常に更新できるよう、今回の正式公開版を v0.8.0 としました。
