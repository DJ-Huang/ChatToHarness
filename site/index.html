ChatToHarness / 控制台

一个窗口管理连接；关闭窗口后，仍可在系统后台图标中随时打开。

01 / CONNECT

本机环境，无需搬家

直接使用已有文件、Git 和命令行工具。保留真实用户环境，让已有开发流程继续工作。

02 / CONTEXT

工程规范，自动交付

按工程和目标目录加载可选 AGENTS.md，支持授权范围内的共享规范；读取和搜索不因缺失引用而中断。

03 / CONTROL

连接状态，一眼看清

有预算的代码搜索、更新检查、连接恢复、停止和日志集中管理。开发入口直接运行最新源码。

COMPUTER USE实验功能

查看窗口，操作应用。

在已授权的窗口内，基于截图执行点击、输入、滚动和拖动。支持 Windows x64 与 macOS arm64。

  • 从插件 → Computer Use → 管理进入，检查权限后主动开启。
  • 首次使用默认关闭，升级保留已保存的开关状态。
  • macOS 需要屏幕录制与辅助功能权限。
  • 按 Esc 或点击 STOP 停止；后续操作由接入的客户端决定。

GET STARTED

三步，把对话接到本机。

1

安装并打开

选择对应系统安装包。运行组件已包含在应用中，无需另外安装开发环境。

2

配置安全通道

在服务控制台准备 Tunnel ID 与 Runtime API Key，填入本机应用，选择工作目录后保存并连接。

3

从客户端发起任务

按接入指南关联同一通道，先尝试只读操作，再在临时目录验证文件读写。

使用前了解

文件目录设置不构成终端沙箱。终端以当前用户权限执行，长时间任务应后台启动并分次读取结果。应用不会把 Runtime API Key 传给工具进程。
