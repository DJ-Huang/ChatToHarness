01 / CONNECT

本机环境，无需搬家

直接使用已有文件、Git 和命令行工具。保留真实用户环境，让已有开发流程继续工作。

02 / CONTEXT

工程规范，自动交付

按工程和目标目录加载 AGENTS.md，索引 rules，规则变化时要求刷新上下文，避免工程之间混用。

03 / CONTROL

连接状态，一眼看清

工具检查、重连、停止和日志集中管理。通道就绪与客户端实际调用分别验证。

GET STARTED

三步，把对话接到本机。

1

安装并打开

选择对应系统安装包。运行组件已包含在应用中，无需另外安装开发环境。

2

配置安全通道

在服务控制台准备 Tunnel ID 与 Runtime API Key，填入本机应用，选择工作目录后保存并连接。

3

从客户端发起任务

按接入指南关联同一通道，先尝试只读操作，再在临时目录验证文件读写。

使用前了解

文件目录设置不构成终端沙箱。终端以当前用户权限执行，长时间任务应后台启动并分次读取结果。应用不会把 Runtime API Key 传给工具进程。
